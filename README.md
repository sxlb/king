# KingJoe

一款仿 Joe 风格的 Typecho 简洁现代主题，内置 41 个 JS 交互模块、16 种短代码、122 个主题配置项。支持暗黑模式、代码高亮、Pjax 无刷新加载，开箱即用。

- **版本**：1.0.0
- **作者**：King
- **要求**：Typecho 1.2+ / PHP 7.4+
- **命名规范**：全站 `joe_` 前缀，CSS 采用 BEM 风格，方便二开与拓展

## 安装

1. 将整个 `King` 文件夹上传至 Typecho 的 `usr/themes/` 目录
2. 进入 Typecho 后台 → 控制台 → 外观，启用 **KingJoe**
3. 点击「设置外观」进行个性化配置

> 主题启用后会自动在 `contents` 表添加 `agree`（点赞）和 `views`（浏览量）字段，无需手动操作。

## 核心功能

### 文章增强
- 文章内视频播放（MP4 / Bilibili / YouTube 嵌入）
- 图片灯箱（点击放大、左右切换、ESC 关闭、移动端适配）
- 图片懒加载（骨架屏占位 + 渐入动画 + IntersectionObserver）
- 文章点赞（24h 内同一 IP/Cookie 限点一次，心跳动画）
- 相关文章推荐（同分类推荐，自定义数量，增强卡片样式）
- 文章过期提醒（超期显示橙色提醒条，自定义天数）
- 阅读进度（顶部彩色进度条 / 右下角圆形浮动进度）
- 阅读时长估算（约 400 字/分钟）
- 文章分享按钮（微博/Twitter/微信二维码/复制链接）
- 文章底部打赏（微信/支付宝收款码）
- 文章字体缩放（A⁻ / A / A⁺ 三档调节，记忆存储）
- 文章导读浮动卡片（右侧悬浮目录导航，hover 显示面板）
- 文章底部作者信息卡片
- 文章底部自定义提示
- 文章页顶部大图（缩略图作 Hero 背景）
- 文章标题居中开关
- 文章摘要 Markdown/短代码清理
- 搜索结果关键词高亮 + 搜索统计 + 智能摘要

## 短代码

在文章编辑器中直接使用以下短代码，共 16 种：

### 视频

```
[video]https://example.com/video.mp4[/video]
[bilibili]BV1xx411c7mD[/bilibili]
[youtube]dQw4w9WgXcQ[/youtube]
```

### 排版

| 短代码 | 说明 | 用法示例 |
|--------|------|----------|
| `[reply]...[/reply]` | 回复可见 | `[reply]登录或评论后可见[/reply]` |
| `[toc]` | 插入文章目录 | `[toc]` |
| `[mark]...[/mark]` | 高亮标记 | `[mark]重点内容[/mark]` |
| `[key]...[/key]` | 键盘按键 | `[key]Ctrl[/key] + [key]C[/key]` |
| `[ruby]汉字{注音}[/ruby]` | 注音 | `[ruby]東京{とうきょう}[/ruby]` |
| `[tips type="info"]...[/tips]` | 提示框 | type: info/warning/danger/success |
| `[collapse title="标题"]...[/collapse]` | 折叠面板 | 点击展开/收起 |
| `[btn url=""]...[/btn]` | 按钮 | `[btn url="https://..." type="primary"]点击[/btn]` |

## 常见问题

### Q：如何添加友链？

在「设置外观 → 友链数据」中按上述格式填写。新建一个独立页面，模板选择「友链」即可。

### Q：代码高亮如何使用？

主题内置 Prism.js，支持 200+ 语言，在文章中使用 Markdown 代码块即可：

````markdown
```php
<?php echo "Hello World"; ?>
```
````

### Q：如何开启搜索关键词高亮？

用户搜索后，文章列表和搜索结果中的关键词会自动高亮（`<mark>` 标签），无需额外设置。

### Q：如何获取百度/Bing 推送 Token？

- 百度：登录 [百度搜索资源平台](https://ziyuan.baidu.com/)，在「普通收录」中获取 token
- Bing：登录 [Bing Webmaster Tools](https://www.bing.com/webmasters/)，在设置中获取 API Key

### Q：如何配置邮件通知？

在「设置外观」中填写 SMTP 相关信息：
1. 开启「评论回复邮件通知」
2. 填写 SMTP 服务器地址（如 smtp.qq.com）
3. 填写端口（465 或 587）
4. 填写邮箱账号和授权码（QQ邮箱等需使用授权码而非登录密码）
5. 如未安装 PHPMailer，系统会自动回退到 PHP 内置 mail() 函数

### Q：如何开启时光机/豆瓣清单？

1. 时光机：在「设置外观 → 时光机分类」中填写一个分类缩略名，然后新建独立页面选择「时光机」模板
2. 豆瓣清单：在「设置外观 → 豆瓣用户 ID」中填写豆瓣 ID 或个人域名，新建独立页面选择「豆瓣清单」模板

### Q：Pjax 是什么？要不要开启？

Pjax 实现了页面无刷新切换（通过 fetch API 局部替换内容），可以保持音乐播放、滚动位置等状态。适合对交互体验要求高的博客。首次加载后页面切换更流畅，但在部分自定义 JS 场景下可能不兼容。

### Q：PHP 版本不满足怎么办？

主题最低要求 PHP 7.4，如果低于此版本，主题会在后台显示错误提示并阻止加载。请升级 PHP 后重试。

### Q：Typecho 默认编辑器会被替换吗？

不会。主题兼容 Typecho 原生编辑器，同时在后台添加了 Markdown 工具栏、短代码插入面板、图片粘贴上传、全屏编辑等增强功能。启用后无需安装任何编辑器插件。

## 安全说明

- 评论内容自动 XSS 过滤（移除 script/iframe/onxxx 事件/javascript: 伪协议）
- 所有用户暴露接口输出均经过 `htmlspecialchars()` / `joe_esc()` 转义
- 安全响应头自动注入（X-XSS-Protection / X-Frame-Options / X-Content-Type-Options）
- 点赞接口 AJAX 请求 24h 频率限制（IP + Cookie 双重校验）
- 友链申请验证码 + URL 格式校验（FILTER_VALIDATE_URL）
- 短代码用户输入内容输出前安全转义
- 自定义 CSS 注入 `<style>` 标签前过滤 `</style>` 逃逸
